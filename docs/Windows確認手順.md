# Windows での確認手順（Linux では確認できなかった項目）

開発環境（Linux）では、レジストリ・黒い窓なしの起動・フォルダ選択の画面・ごみ箱が使えないため、次の項目を Windows 10/11 で確認してください。
実際の録画や普段の設定に影響しないよう、**確認用のユーザーデータ置き場と、コピーした録画**を使います。

## 0. 準備（確認用の保存先を使う）

```bat
set RECSORT_DATA_DIR=%TEMP%\RecSort確認用
mkdir "%USERPROFILE%\Videos\RecSort 確認 用"
```

`RecSort 確認 用` に、確認してよい動画（コピー）を数本入れます。同じファイルのコピーも1本作ります。
> 自動起動（手順 2）は、登録したコマンドが `RECSORT_DATA_DIR` を引き継がないため、普段の保存先（`%LOCALAPPDATA%\RecSortV1`）を使います。
> 普段の保存データを触りたくない場合は、手順 2 の前に `%LOCALAPPDATA%\RecSortV1` をフォルダごとコピーしておいてください。

## 1. バッチからの手動起動

1. `RecSortを起動.bat` をダブルクリック（初回は .venv の作成と部品のインストールで数分かかる）
2. 確認: 黒い窓に「起動しました: http://127.0.0.1:8765/」が出てから、既定のブラウザで画面が開く
3. もう一度ダブルクリック → 2つ目の黒い窓は「すでに起動しています」を表示して閉じ、ブラウザで画面が開く
4. ブラウザのタブを閉じて、アドレスバーに `http://127.0.0.1:8765/` を入力して開ける
5. 黒い窓を閉じる → ブラウザの画面下に「サーバーに接続できません…」が出る

## 2. ログイン時の自動起動

1. 手順 1 で起動 → 設定 →「ログイン時に起動するようにする」→「有効にする」
2. 確認: `reg query HKCU\Software\Microsoft\Windows\CurrentVersion\Run /v RecSort` に
   `"…\.venv\Scripts\pythonw.exe" "…\main.py" --background` が登録されている
   （タスクマネージャー →「スタートアップ アプリ」にも出る）
3. 黒い窓を閉じ、Windows からサインアウト → サインイン
4. 確認: 黒い窓もブラウザも開かない。ブックマークから `http://127.0.0.1:8765/` を開くと画面が出る
5. 確認: `%LOCALAPPDATA%\RecSortV1\server.log` に「（ログイン時の自動起動）」の行がある
6. 自動起動中に `RecSortを起動.bat` をダブルクリック → 2つ目は起動せず、ブラウザで画面が開く
7. 設定 →「RecSort を終了」→ 確認で「終了する」→ ブラウザに「終了しました」と出て、アドレスを開き直すと接続できない
8. ポート競合: `python -m http.server 8765 --bind 127.0.0.1` を別の窓で動かしたまま、サインアウト → サインイン
   → 「RecSort を起動できませんでした」のダイアログに、別のアプリが使っていることと直し方が出る（server.log にも記録）
9. 解除: 設定 →「自動起動を解除する」→ `reg query …\Run /v RecSort` が「見つかりません」になる。
   次のサインインでは起動しない。ほかのアプリの Run の登録が変わっていないこと
10. フォルダを移動した場合: RecSort のフォルダを別の場所に移してから手動起動 → 設定に「場所と違います」と出る

## 3. フォルダ選択・スキャン・再生

1. ホーム →「参照…」→ フォルダ選択の画面が前面に出る → `RecSort 確認 用` を選ぶとパスが入る
2. 「このフォルダを調べる」→ 進み具合が表示され、終わると録画の本数が出る
3. 存在しない `D:\ない フォルダ` を入力 → 「フォルダが見つかりません」と表示
4. ファイル一覧で mp4（H.264）を選ぶ → Edge/Chrome で再生・シークできる（.ts などはブラウザが再生できない旨と「保存場所を開く」）
5. 「保存場所を開く」→ エクスプローラーでそのファイルが選ばれた状態で開く

## 4. 似た録画の比較

1. 同じ動画を別の解像度で書き出したもの（例: スマホと PC の録画）を入れて調べる
2. 整理のおすすめ →「似た録画」→「比較する」→ 場面の画像が並び、違う場面が赤枠で出る。場面を押すと両方の動画が同じ位置に移る
3. 「音声を比べる」→ 結果が出る。「すべて同時に再生」で基準の録画の音だけ鳴り、「この音を聞く」で切り替わる
4. 「これを残す」→ もう1本の判断が変わらない（「未判断」のまま）
5. もう1本の「削除候補にする」→ 確認 →「削除候補」になる

## 5. ごみ箱への移動と復元（確認用のコピーだけで）

1. 削除候補 → 最終確認へ →「ごみ箱へ移す」→ 確認で「いいえ」→ 何も移動しない
2. もう一度「ごみ箱へ移す」→「はい」→ 結果に「移動した」と出る。エクスプローラーで元の場所から消えている
3. Windows のごみ箱を開き、移動したファイルを右クリック →「元に戻す」→ 元の場所に戻る
4. 別に、開発用のツールで実機のごみ箱を試験できる（ダミーファイルだけを使う）:
   `.venv\Scripts\python.exe tools\recycle_bin_live_test.py`

## 6. 結果の記録

各項目の結果（OK / NG とメッセージ・スクリーンショット）と、Windows のバージョン・ブラウザの種類を記録してください。
NG の場合は `%LOCALAPPDATA%\RecSortV1\server.log`（自動起動時）または黒い窓の表示を添えてください。
